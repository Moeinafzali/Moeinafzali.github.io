Privacy Policy

Last updated: November 2, 2026

Megawatt Racks Uploader is a private tool used only by the owner of the Megawatt Racks YouTube channel. It is not offered to the public.

What the tool accesses

With the channel owner's permission, the tool uses YouTube API Services to upload videos and thumbnails to the owner's channel, and to read that channel's own information and analytics. It does not collect information about viewers or any other users.

How information is stored

The Google sign-in token and channel analytics are stored on the channel owner's own computer. This tool does not run a server or a database.

Sharing

This tool does not sell information. Its operation involves no sharing of user data with third parties. Channel information may be processed by the AI tools the owner uses to run the channel, only to help produce and improve the channel's own videos.

Google and YouTube

This tool uses YouTube API Services. By using it, you are also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from your Google account permissions page. Deleting the token from the owner's computer also removes the stored access.
